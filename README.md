# TypeScript Problem-Solving
Welcome to my TypeScript problem-solving repository. This space contains various typescript problem solutions and technical write-ups documenting my learnings.

## Overview

This repository focuses on exploring advanced TypeScript concepts, strong type modeling, and object-oriented programming patterns. It acts as a practical demonstration of addressing real-world development issues through strict typing, custom generics, asynchronous methods, and sophisticated type.

## Contents

* **`solutions.ts`**: A collection of strongly typed TypeScript implementations, featuring strict parameter and return types, class inheritance, access modifiers, and asynchronous utility handling.
* **Technical Write-ups**: Deep dives into core architectural patterns and type system features:
  * [Access Modifiers in TypeScript OOP](./access-modifiers-typescript-oop.md) - A detailed look at encapsulation, visibility control, and data hiding using `public`, `private`, `protected`, and `readonly`.
  * [Combining Union and Intersection Types](./combining-union-intersection-typescript.md) - Practical explorations of advanced type compositions to build flexible yet type-safe data structures.
